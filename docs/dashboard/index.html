Definitions. Delivered orders are orders with status delivered and a delivery date. An order is late when its delivery date (calendar day) is after the promised (estimated) delivery date, the same rule as fct_order_delivery. Seller, product and category come from the order's first item; reviews use each order's latest review. Data. Aggregates of the public Olist dataset (Sep 2016 – Aug 2018), produced by the SQL in src/tools/dashboard_queries.py, which src/tools/export_dashboard_data runs against Gold. The published CSVs (in docs/dashboard/data/) come from the raw public files, so they differ by one order from Gold, which also holds the CDC test update. Distance bands use the public Olist geolocation file, which the platform does not ingest yet. Everything in the With ideal data tab is simulated.
